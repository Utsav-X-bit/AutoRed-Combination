#   torch 2.1.x     — highest version supported by CUDA driver 12.x (≈ 520.xx)

#   pydantic 1.10.13       — required by vllm 0.2.7 (vllm 0.3+ migrated to v2)
#   transformers 4.38.2    — last version compatible with torch 2.1.x pytree API
#   numpy <2.0             — required by thinc (spaCy backend); numpy 2.x breaks it
